## 📐 2. Fondements Mathématiques & Algébriques

### 2.1 Machine Virtuelle Vectorielle Latente (`LatentNeuralVM`)

Pour dépasser le paradigme purement statique des représentations symboliques vectorielles, nous formulons une machine à états finis continue opérant strictement sur la sphère $\mathbb{S}^{D-1}$ :
$$S_{t+1} = \sigma_{\mathbb{S}}\left(S_t \circledast R_{\text{op}} \circledast \text{Input}\right)$$

Chaque transition programmable est encodée comme une superposition unitaire de 4 rôles orthogonaux :
$$T = \frac{R_{\text{state}} \circledast S_{\text{from}} + R_{\text{trig}} \circledast V_{\text{trig}} + R_{\text{target}} \circledast S_{\text{to}} + R_{\text{escrow}} \circledast V_{\text{escrow}}}{\| \dots \|_2}$$

Lorsqu'un Gigatoken d'entrée $X$ est présenté, la VM calcule le score de compatibilité conjointe :
$$\text{Score}(T) = \frac{1}{2} \left( \langle S_{\text{current}}, S_{\text{from}} \rangle + \langle X, V_{\text{trig}} \rangle \right)$$

Si $\text{Score}(T) \ge \tau_{\text{vm}}$ (avec sélection déterministe par $\text{argmax}$ en cas de multiples candidats éligibles) :
- L'état latent bascule vers $S_{\text{to}}$ sans dérive unitaire ($\|S_{t+1}\|_2 = 1$).
- L'action d'escrow $V_{\text{escrow}}$ est émise, déclenchant la libération conditionnelle d'énergie ou d'actifs matériels au bénéficiaire sans intermédiaire.

### 2.2 Causalité Formelle & Do-Calculus Vectoriel

Dans le cadre du Do-Calculus de Pearl transposé à l'algèbre vectorielle holographique, une observation passive $P(Y \mid X)$ reflète une simple corrélation affectée par d'éventuels facteurs de confusion latents $Z$.
Nous définissons l'opérateur d'intervention unitaire $do(X)$ :
$$do(X) = R_{do} \circledast X, \quad \text{avec } \mathcal{F}(R_{do}) \text{ unitaire}$$

L'expérimentation scientifique consiste à couper les dépendances antérieures dans l'état latent en substituant la composante causale par chirurgie géométrique :
$$S_{do(X)} = \frac{S_{\text{base}} - \text{proj}_{X}(S_{\text{base}}) + (R_{do} \circledast X)}{\| \dots \|_2}$$

L'**Effet Moyen de Traitement Latent (ATE)** est alors calculé entre les états factuels et contrefactuels :
$$\text{ATE} = \left\| \mathbb{E}[Y \mid do(X)] - \mathbb{E}[Y \mid do(\neg X)] \right\|_2$$
$$\text{Discrepancy} = \left| \text{ATE} - r_{\text{obs}}(X, Y) \right|$$

Si $\text{ATE} \ge \tau_{\text{causal}}$, l'Académie valide que $X$ est une cause authentique et non un artefact fortuit.

### 2.3 Consensus Byzantin Sphérique (BFT Géométrique de Weiszfeld)

Face à un ensemble de $n$ vecteurs émis lors d'une délibération collective, comprenant jusqu'à $f < n/3$ vecteurs byzantins adversariaux $V_b$, la moyenne arithmétique euclidienne est biaisée.
Nous formulons l'estimateur de la Médiane Géométrique Sphérique de Weiszfeld régularisée :
$$\mu^{(k+1)} = \frac{\sum_{i=1}^n w_i^{(k)} V_i}{\left\| \sum_{i=1}^n w_i^{(k)} V_i \right\|_2}, \quad w_i^{(k)} = \frac{1}{\max(\epsilon, \arccos(\langle \mu^{(k)}, V_i \rangle))}$$

À convergence géodésique, la distance angulaire $d_i = \arccos(\langle \mu^*, V_i \rangle)$ est évaluée pour chaque votant. Les $\lfloor n \cdot r_{\text{byz}} \rfloor$ agents dont la déviation angulaire excède la borne supérieure de tolérance sont exclus :
$$\text{ByzantineFilter}(V_i) \Longleftrightarrow d_i > \text{Quantile}_{1 - r_{\text{byz}}}(\{d_j\})$$

Le consensus final agrège exclusivement les nœuds vérifiés conformes, garantissant $\langle \mu^*, V_{\text{true}} \rangle \ge 0.90$ même sous attaque antipodale directe.
